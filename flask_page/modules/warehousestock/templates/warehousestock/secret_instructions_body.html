1. The Best Endpoints inside afwan_cron
Modular Integration

The module is registered in afwanhaziqmy.py with a dedicated, isolated namespace that avoids collisions with existing routes (like /login or root APIs):

Endpoint / URL Type Description & Target View
/warehousestock Recommended Primary module root: Opens the Executive Warehouse Dashboard (redirects to login if unauthenticated).
/warehouse Alias Convenient short alias redirecting automatically to /warehousestock (including any subpath queries).
Complete Sub-Routes Breakdown:
Route Method View / Functionality Action
/warehousestock/ or /dashboard GET Executive Dashboard: Real-time KPIs, stage distribution donut chart, customer volume bar chart, shortage alerts. Open
/warehousestock/login GET, POST Sign In Portal: Secure authentication with 1-click test credential auto-fill buttons. Login
/warehousestock/stock-control GET, POST Stock Control Matrix: Interactive 8-channel matrix with live inter-channel transfer modal and auto-balance. Open
/warehousestock/master-stock GET, POST Master Stock Catalogue: Search all parts across 6 customers, filter by machine, add items, and adjust audits. Open
/warehousestock/master-stock/export GET CSV Export: One-click download of the complete master stock inventory. Download
/warehousestock/mc-plan GET, POST MC Plan & Shortages: Machine production scheduling, monthly forecasts, and real-time shortage badges. Open
/warehousestock/washing-qa GET, POST Washing & QA Operations: QA inspection approvals, defect re-wash rejections, and NG scrap disposal. Open
/warehousestock/daily-stock GET, POST Daily Movements Log: Daily sheet movements (IN/OUT), date pills, and Pedma delivery schedule balances. Open
/warehousestock/instructions GET System Reference Manual: Complete documentation, credentials, and Excel mapping guide. Current Page
/warehousestock/profile GET User Profile: View current authenticated user, assigned role, and permissions. Profile
/warehousestock/api/stats GET (JSON) JSON Stats API: Stage volume totals across all 8 WIP channels for API consumers and charts. JSON
/warehousestock/api/items/search GET (JSON) JSON Item Search API: Live autocomplete / item search by part number or delivery part number. JSON
2. Pre-Configured User Accounts & Roles
Role-Based Access Control

Passwords are securely encrypted with werkzeug.security PBKDF2 hashing. The login screen also features 1-click auto-fill buttons for instant testing:

3. Excel Tabs & Web Architecture Mapping
Direct Sheet Parity
Excel Sheet / Tab Web Module & Link Capabilities & Business Logic
stock control Stock Control Interactive stage matrix tracking inventory across: Warehouse, QA Transit, Return QA, Wash Area, QA Area, Production, Finished Goods, and NG - Disposed. Features live stage-to-stage transfer modal with automatic balance recalculations.
master Master Stock Complete master catalogue of all 940+ parts across 6 customers. Search by Part No, Delivery Part No (Pedma), STD PKG, Machine No, Material Size. Includes One-Click CSV Export and stock audit adjustments.

29.04.15 – 09.05.15 Daily Movements Daily stock movement log tracking IN/OUT movements, HEATING, QA, W/H, Total Cartons & KPCS, alongside Pedma delivery schedule balances. Includes modal to log new daily stock movements.
